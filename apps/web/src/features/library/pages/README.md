# features/library/pages

## 목적

콘텐츠 기능의 라우트 화면 세 개를 둡니다. 주소 연결은 `../routes.tsx`가 합니다.

## 주요 파일

| 파일 | 경로 | 역할 |
|---|---|---|
| `content.tsx` | `/p/:slug/content` | 콘텐츠 목록. 영상 탭(`../components/VideoListPage.tsx`)과 클립 탭(`?tab=clips`, `../components/ClipsPanel.tsx`)을 둡니다. 영상을 고르면 영상 상세로 이동합니다 |
| `video_detail.tsx` | `/p/:slug/videos/:videoId` | 영상 상세. 본문은 플레이어, 준비 진행, 클립(12행이 넘으면 접음) 순서입니다. 준비가 막힌 영상은 준비 진행을 플레이어 위로 올리고 실패 사유를 펼칩니다. 준비가 끝난 영상은 준비 진행을 단계 칩 한 줄과 안내 줄(확인 필요 경고, 건너뛴 사유)로 접습니다. 장면 요약을 받지 못한 영상은 `요약 재요청`이 확인 창을 엽니다. 사이드바에는 메타·등록 정보·파일을 두고, 관리자에게는 분석본 정리 버튼을 둡니다 |
| `video_clips.tsx` | `/p/:slug/videos/:videoId/clips` | 클립 보기. 왼쪽에서 클립 구간만 재생하고, 오른쪽에 그 클립이 작업 흐름의 어느 단계까지 갔는지 보입니다. 판정 기능과 구간 편집은 없고, 구간은 분석이 나눈 그대로 보입니다. 클립 사이 이동은 목록의 행을 눌러서 합니다 |

## 설계 이유

- 주소의 프로젝트와 영상의 프로젝트가 다르면 영상 없음으로 막고, 영상이 속한 프로젝트로 가는 링크만 줍니다. 다른 프로젝트의 영상을 현재 프로젝트 주소 아래에서 보여 주면 맥락이 틀립니다.
- 클립 보기에는 판정 기능이 없습니다. 클립이 어떻게 나뉘었는지는 라벨러도 봐야 하므로 프로젝트 멤버라면 누구나 엽니다.
- 변환 실패처럼 기다려도 풀리지 않는 영상에는 기다리라는 안내 대신 원인과 다음 할 일을 버튼으로 제공합니다. 재생본이 없는 영상에서는 구간 추가를 숨깁니다.
- 경계는 영상을 보면서 정합니다. 재생 위치로 시작점·끝점을 넣고, 위치를 읽지 못하면 0이 아니라 `—`로 둡니다.
