# features/projects/pages

## 목적

프로젝트 목록·생성·설정 화면을 둡니다. 주소 연결은 `../routes.tsx`가 합니다. 목록 화면은 홈(`features/me/pages/home.tsx`)도 그리므로 `../index.ts`로 내보냅니다.

## 주요 파일

| 파일 | 경로 | 역할 |
|---|---|---|
| `projects.tsx` | `/projects` | 프로젝트 목록 `ProjectsPage`. 작업자에게는 행 목록(머리글자·이름과 설명·역할·상태, 전환기에서 고른 프로젝트에는 `지금 보는 프로젝트` 표시)을, 최고관리자에게는 분석 방식·계약 목표·마감·상태·만든 날을 비교하는 표를 보입니다. |
| `project_new.tsx` | `/projects/new` | 프로젝트 생성 폼(최고관리자). 이름·주소·설명·분석 방식을 받습니다. 프로젝트는 서버가 기본 조직에 둡니다. 고른 방식을 이 서버에서 쓸 수 없으면(`available`) 추가를 막고 서버가 준 이유를 씁니다. 등록한 연결이 없어서 막힌 방식이 있으면 폼 위에 `NoConnectionNotice`로 자격증명 연결 화면을 안내합니다 |
| `project_settings.tsx` | `/p/:slug/settings` | 프로젝트 설정(프로젝트 관리자). 왼쪽 메뉴(기본 정보·작업 가이드, 캡션 품질검수, 비식별화·분석 연동, 위험 영역), 바뀐 필드만 보내는 저장 막대, 분석 연동(저장소·분석 대상 카드, 읽기 전용 연동 상태), 삭제를 둡니다. 분석본 정리는 영상 상세의 파일 묶음에서 영상마다 합니다 |

## 설계 이유

- 모든 행이 같은 값인 열은 그리지 않습니다. 역할 열은 행마다 역할이 다를 때만, 상태 열은 활성이 아닌 프로젝트가 있을 때만 둡니다.
- 처리 옵션은 모든 프로젝트가 같은 기본값을 쓰므로 입력란을 두지 않습니다. 작업자가 겪는 값(캡션 최소 길이·반려 사유)은 작업 가이드 페이지에 읽기 전용 안내로 보입니다. 동시 보유 한도와 보유 시간은 없어 작업 배분 페이지를 두지 않습니다.
- 설정을 저장할 때 서버 값과 다른 필드만 보냅니다. 모든 값을 보내면 그사이 다른 관리자가 바꾼 값을 덮어씁니다. 저장하지 않고 떠나면 확인 창을 띄우고, 그 창에서 저장할 수 있습니다.
- 되돌릴 수 없는 선택(프로젝트 주소·분석 방식)에만 잠금 표시와 만든 뒤 바꿀 수 없다는 문장을 붙입니다.
- 위험 영역은 삭제 권한이 있는 최고관리자에게만 보입니다. 누를 것이 없는 절을 열게 하지 않습니다.
- 주소 규칙은 계약(`ProjectCreateRequest.slug`)이 기준이고, 화면은 같은 식으로 먼저 거릅니다. 두 규칙이 다르면 한쪽에서만 통과하는 입력이 생깁니다.
