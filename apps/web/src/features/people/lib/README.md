# features/people/lib

## 목적

멤버 기능의 순수 규칙과 표기를 둡니다. 부품 밖에 두어서 렌더 없이 테스트하고, 부품 사이의 import 순환을 피합니다.

## 주요 파일

| 파일 | 역할 |
|---|---|
| `roles.ts` | 프로젝트 역할 목록(`ROLES`, 업무 흐름 순)과 그 타입, 역할마다 하는 일을 한 문장으로 쓴 설명(`ROLE_DESC`, 초대 창과 설정 탭에서 사용) |
| `member_status.ts` | 멤버십 상태 이름(`MEMBER_STATUS_LABEL`·`memberStatusLabel`). 멤버 표·서랍·머리 요약이 씁니다 |

## 설계 이유

- 역할 목록과 상태 이름은 여러 부품이 함께 쓰므로 부품 밖 이 폴더에 둡니다. 참여 기간이 없으므로 상태는 저장된 `status`를 그대로 씁니다.
