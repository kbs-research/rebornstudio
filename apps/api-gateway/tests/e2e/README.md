# tests/e2e

API 바깥에서 전체 흐름을 차례로 거치는 종단 테스트입니다. 스모크(헬스·인증·관리 API 하나씩)와 walking skeleton(등록, 분석, 라벨링, 검수, 납품을 차례로 거치는 흐름. 분석으로 생긴 클립은 허가 상태라 바로 작업이 만들어집니다)을 봅니다.

## 주요 파일

| 파일 | 역할 |
|---|---|
| `test_e2e_walking_skeleton.py` | Walking Skeleton E2E 테스트입니다. 한 흐름이 끝까지 동작하는지 봅니다. |
| `test_smoke.py` | 헬스 체크와 주요 흐름을 1개씩 확인하는 스모크 테스트입니다. 관리자가 만든 계정의 로그인, 공개 가입·외부 로그인·가입 승인 경로가 없는지도 봅니다. |

## 설계 이유

폴더 규칙과 둘 이상에 걸친 파일의 위치는 [`../README.md`](../README.md)에 있습니다.
한 흐름이 끝까지 가는지만 봅니다. 단계별 규칙은 각 도메인 폴더에 있습니다.

## 의존성

- 픽스처(`client`·`admin_token`)는 상위 `tests/conftest.py`, 시드 헬퍼는 `tests/_helpers.py`에서 옵니다.
- 모듈 이름은 폴더가 달라도 전체에서 유일해야 합니다. 하위 폴더에 `__init__.py`를 두지 않기 때문입니다.

## 남은 일

- 없음. 파일을 더하면 위 표에 한 줄을 더합니다.
